zx80.rom - The 4K BASIC ROM, CRC32 4c7fc597, matching MAME's "zx80" romset
default BIOS. This is the ROM dump almost every surviving/emulated unit
runs; there were two revisions of this ROM (an earlier v1, and a later,
bug-fixed v2) and which one this dump is remains unconfirmed pending
disassembly.
